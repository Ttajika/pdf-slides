# PDFスライド

`pdf/` に置いた PDF を、ブラウザでスライドとして表示します。iPad で書いた手書き・ポインター・板書とページ送りを、PC へリアルタイムに配信できます。PC 側では録画もできます。

公開ページ：<https://ttajika.github.io/pdf-slides/>

## アップロードして共有する（研究発表向け）

git を使わず、ブラウザから PDF をアップロードして共有できます。

1. `upload.html` で、アップロード用パスワードを入れて PDF を選びます。
2. 次の 2 本のリンクが発行されます。有効期限は 30 日です。
   - **共有リンク** `viewer.html?s=ID`：参加者に事前に配るリンクです。当日、発表者が配信を始めると、そのまま追従します。
   - **発表者リンク** `viewer.html?s=ID&k=秘密鍵`：配信、PDF の差し替え（共有リンクは変わらない）、期限の延長、削除ができます。**人に渡さないでください。**
3. 当日は、iPad で発表者リンクを開いて配信ボタンを押します。ログインは要りません。

発表者リンクは、開いた端末の `upload.html` の「この端末でアップロードしたもの」に控えが残ります。外部の発表者に頼むときは、アップロード用パスワードを伝えるか、こちらでアップロードして発表者リンクを渡します。

### 最初に一度だけ：Supabase の設定

1. Supabase ダッシュボードの SQL Editor に `supabase/setup.sql` を全部貼り付けて実行します。
2. 末尾のコメントにある `select public.slide_set_password('...');` を、自分のパスワードに書き換えて実行します。パスワードを変えるときも同じ操作です。

仕組み：PDF は公開バケット `slides` に、推測できないランダムなパスで置かれます。一覧の取得・上書き・削除は、ポリシーで禁止しています。パスは共有リンクの ID を使って問い合わせたときにしか返らず、期限が切れると返らなくなります。期限切れや差し替え前のファイルは自動では消えません。`setup.sql` の末尾にある「掃除」の SQL で一覧を出し、ダッシュボードの Storage から削除してください。無料プランの容量は 1GB です。

## GitHub に置いた PDF を使う

1. PDF を `pdf/` に追加して push します。サブフォルダは 1 段まで使えます（例：`pdf/micro/01.pdf`）。
2. 一覧ページを開き、配信コードを決めます（既定は `1`）。
3. iPad で「配信（iPad）」を開き、🔑 からログインし、配信ボタンを押します。
4. PC で同じコードの「受信（PC）」を開きます。

URL を直接書くときは次のとおりです。

| 用途 | URL |
|---|---|
| ふつうに見る | `viewer.html?file=pdf/xxx.pdf`（`#5` で 5 ページ目から） |
| 配信（iPad） | `viewer.html?file=pdf/xxx.pdf&presenter=1&live=CODE` |
| 受信（PC） | `viewer.html?file=pdf/xxx.pdf&live=CODE` |

配信中に QR ボタンを押すと、参加者用の URL と QR コードが出ます。

録画したい PC では、受信用の URL（共有リンクを含む）の末尾に `&rec=1` を付けて開くと録画ボタンが出ます。画面には案内を出していません。

## 操作

| 操作 | キー / 動作 |
|---|---|
| ページ送り | ← → / Space / 指で左右スワイプ |
| 手書き | ✏️ または D。Apple Pencil を当てると自動で手書きモードになる |
| ペン / 蛍光ペン / 消しゴム / ポインター | P / H / E / L |
| 取り消し | ⌘Z / Ctrl+Z |
| 板書（白紙のポップアップ、ページごと） | 「板書」または B。Esc で閉じる |
| 全画面（PC） | ⛶ または F |

Apple Pencil を使っているときは、指では書けず、スワイプでページを送ります。

書き込みはその端末のブラウザ（localStorage）にだけ保存されます。クラウドには保存されません。

## 仕組み

- 表示：PDF.js
- 配信：Supabase Realtime（Broadcast / Presence）。データベースには書き込みません。
- `js/slide-live.js` と `js/slide-sync.js` は `nuce-slides/2027` からコピーしたもので、PDF 用に次の手を加えています。
  - `slide-live.js`：受信用 URL に `?file=` を残す。線の太さを canvas の解像度に合わせる（`lineScale` / `boardLineScale`）。録画ファイル名に PDF 名を使う（`recName`）。
  - `slide-sync.js`：`syncData: false` のとき、ログインだけ使い、データは同期しない。
- 配信できるのは `js/slide-live.js` の `CONFIG.presenterIds` に入っている ID だけです。
